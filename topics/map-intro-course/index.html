Introduction to Spatial Analysis for Infectious Diseases

An introductory course from the Malaria Atlas Project covering data management, R, QGIS and spatial data — a good place to start.

Malaria Atlas Project — http://malariaatlas.org/training

This is a suite of introductory materials developed by the Malaria Atlas Project, and covers many of the technical subject areas in the other topics on this site. The training materials are intended for an epidemiology audience, but entomological collaborators of the Vector Atlas will find strong cross-over and familiarity with the applications and skills. The materials are intended to be delivered through an in-person course, but can also be followed independently online.

The best place to begin is on the home page (Before We Get Started), which links to data, notes, and has installation instructions for the software used.
