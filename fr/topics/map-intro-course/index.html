Introduction à l'analyse spatiale pour les maladies infectieuses

Un cours d’introduction du Malaria Atlas Project sur la gestion des données, R, QGIS et les données spatiales — un bon point de départ.

Malaria Atlas Project — http://malariaatlas.org/training

🇬🇧 Ressource disponible en anglais uniquement — nous n’avons pas identifié d’équivalent francophone. Vous en connaissez un que nous devrions référencer ? Écrivez-nous.

Il s’agit d’un ensemble de supports d’introduction développés par le Malaria Atlas Project, qui couvre plusieurs des domaines techniques abordés dans les autres thèmes de ce site. Ces supports s’adressent à un public d’épidémiologistes, mais les collaborateurs et collaboratrices entomologistes du Vector Atlas y retrouveront de nombreux recoupements avec leurs propres applications et compétences. Ils sont conçus pour être enseignés en présentiel, mais peuvent aussi être suivis de façon autonome en ligne.

Le meilleur point de départ est la page d’accueil (Before We Get Started), qui renvoie vers les données et les notes de cours, et contient les instructions d’installation des logiciels utilisés.
